# Trader Game

This is second-year university assignment I worked on with my classmates [@hakanozbay](https://github.com/hakanozbay) and [@darylharrison](https://github.com/darylharrison) in the summer term of 2008.

Back then, we developed the game using a stack of PHP5, Java 5, JavaScript and Postgres. As of November 2026, I have upgraded it to work on PHP8, Java 25 and Postgres 18. The JavaScript code was built on jQuery which I have decided not to upgrade yet as it still works for the most part.

It is my intention not to refactor the code unless it makes it easier to keep it running on newer versions of PHP and Java. Seeing the code preserved as it was then gives me an insight into how I thought about code design as a young naive student. I find it a little amusing to look at the choices we made at the beginning of our programming journey and there is also a certain magic and wonder of possibility about the way we construct solutions when we don't know much about coding.

Then there's the memories of hacking away in the computer lab with my classmates into late hours, ordering chinese food and the evening scramble through the library to find a way to submit our code before the deadline at midnight. However this was more than an assignment. For most of us at the time it was our first real experience at coding in a team, using source version control (SVN I might add). It was about working together with a common aim (pass the assignment) but also and more importantly just to have fun building something big.

## How to start the game

```
docker-compose up
```

Open a browser tab in [http://localhost:8080]().
